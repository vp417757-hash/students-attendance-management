# students-attendance-management
📚 Student Attendance Management System – Mood Board 📚
🟦 About the App

Student Attendance Management System is a modern application designed in Figma to help teachers manage student attendance easily and efficiently. The simple interface, clear layout, and organized features make attendance tracking quick and convenient.

🎨 Color Palette

🟦 Primary – #2563EB
💙 Represents Trust, Technology & Reliability

🟩 Secondary – #22C55E
✅ Represents Present, Success & Progress

🟥 Accent – #EF4444
❌ Highlights Absence & Important Alerts

⬛ Neutral Dark – #1F2937
🖤 Improves Readability & Contrast
